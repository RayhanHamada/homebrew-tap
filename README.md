# Homebrew tap

## android-cli-gui

Unofficial GUI for the official Android CLI. Requires macOS 15 or later.

```sh
brew install RayhanHamada/tap/android-cli-gui
```

The formula is generated by the release workflow in
[RayhanHamada/android-cli-gui](https://github.com/RayhanHamada/android-cli-gui)
when a `vX.Y.Z` tag is pushed.
