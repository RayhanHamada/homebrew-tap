# Homebrew tap

## android-cli-gui

Unofficial GUI for the official Android CLI. Requires macOS 15 or later.

```sh
brew tap RayhanHamada/tap
brew trust --cask RayhanHamada/tap/android-cli-gui
brew install --cask RayhanHamada/tap/android-cli-gui
```

This installs `Android CLI GUI.app` in `/Applications` and the official
`android-cli` cask as a dependency. Launch it from Applications, Launchpad, or
Spotlight.

Homebrew 7 requires trusting third-party casks before installation. On older
Homebrew versions the `brew trust` step can be skipped.

The cask is generated by the release workflow in
[RayhanHamada/android-cli-gui](https://github.com/RayhanHamada/android-cli-gui)
when a `vX.Y.Z` release is published.
